# Roadmap

These are plans, not features. None is a commitment, and none has a date. The order may change.

## Now

- **Developer documentation.** This repository: the vision, the architecture overview, this roadmap and the contribution instructions.
- **Developer Mode on the website.** A public page that introduces the project and links here.

## Next

- **Sharing approved source components.** Parts of the application that are approved for release will be published here, with setup steps and tests. Nothing is approved yet.
- **Development tasks.** A list of tasks that are open to contributors, each with what "done" means and how it is tested.
- **Contribution workflow for code.** Review rules, required checks and branch protection, once there is code to review.

## Later

- **API documentation.** A versioned description of the public interfaces.
- **Specialist registration.** A reviewed way to propose a new fictional specialist that follows the house rules and passes the checks.
- **Model guides.** Set-up notes for local and hosted models, each with the checks it must pass before it is offered.
- **Speech engines.** Documentation for speech options, keeping device speech and premium speech separate.
- **Evaluation tools.** Shared ways to run and report structured evaluations, with independent review.
- **Native app.** A native app is being considered. Nothing native exists yet.

## Not planned

- Presenting any specialist as a real person, a court or a professional adviser.
- Collecting visitors' conversations on a server by default.
