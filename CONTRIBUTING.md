# Contributing

Thank you for helping with Malimar Ballroom. Anyone can contribute. Work done with an AI tool is welcome when a person stands behind the pull request.

## What you can contribute today

This repository holds documentation. The application source is private, so code contributions to the application are not open yet. Today you can:

- report a problem with the public website or with these documents;
- suggest an improvement;
- fix or improve a document.

[docs/ROADMAP.md](docs/ROADMAP.md) says what is planned, including sharing approved source components.

## How to contribute

1. Read [docs/VISION.md](docs/VISION.md), so you know the project's principles and limits.
2. For a problem or an idea, open an issue with the matching template.
3. For a document change, fork the repository, create a branch and make one focused change. The steps are in [docs/DEVELOPMENT-SETUP.md](docs/DEVELOPMENT-SETUP.md).
4. Open a pull request against `main`. Say what changed, how you checked it, and whether an AI tool helped.

A maintainer reviews every pull request before it is merged. Contributors do not get direct write access to protected branches.

## House rules

- Every specialist stays fictional. Do not propose a seat that imitates a real person, an office holder, a court, a firm or a company.
- Keep the disclaimer true: general information only, not legal, tax, investment or medical advice.
- Label plans as plans. Do not describe something as working unless it is.
- Do not post keys, tokens, signed links, passwords or personal data.
- Do not post real legal matters, client details or financial account information, even as examples.
- Report a security problem privately. See [SECURITY.md](SECURITY.md). Do not use a public issue.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
