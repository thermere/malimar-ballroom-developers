# Malimar Ballroom: developer documentation

Malimar Ballroom is a conversation room of fictional AI specialists. A person asks a question in ordinary language. The specialists give short contributions, may challenge a specific claim, and let the person interrupt, correct or redirect the conversation. The aim is the most accurate answer the available evidence supports, given quickly.

This repository is the public home for the project's developer documentation: the vision, an architecture overview, the roadmap, and the contribution instructions.

- Website: https://malimarballroom.com/
- Developer Mode page: https://malimarballroom.com/developers

## What is public and what is private

- **Public here:** documentation, the roadmap, contribution instructions, issue and pull-request templates, the security policy and the code of conduct.
- **Private:** the application's source code and the project's research components. They are not in this repository, and this repository does not link to them.
- **Not available yet:** a runnable copy of the application. Setup steps will be added when approved source components are shared here.
